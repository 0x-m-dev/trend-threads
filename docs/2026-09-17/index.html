Nvidia announces native GPU programming in Rust

NVIDIA is compiling GPU kernels from Rust to PTX. cuda-oxide is the SIMT track: custom rustc backend, pinned nightly, Linux, compute capability 8.0+. cutile-rs is the tile track: stable Rust 1.89+, CUDA 13.3, already on crates.io. HuggingFace Grout and mistral.rs ship it. cuda-oxide is still early alpha. Interop with CUDA C++ and Python is planned. 841 points.

One Year of Sponsored Servo Development

Josh Bowman-Matthews (@jdm) did a year part time on Servo, paid by OpenCollective and GitHub donations. He nominated 8 maintainers, reviewed 1150 pull requests, and filed 114 issues for newer contributors (92% fixed). He also helped a JS engine rewrite that was panicking on garbage collection, and another contributor got a grant. That was Servo's first donation funded role. 239 points.

My temporary PHP fix from 2014 has nearly 20M installs. Today I'm deprecating it

Jake A. Smith wrote 174 lines of PHP in 2014 so AOL's CMS could drop pecl_http without touching every URL call. Nearly 20 million Packagist installs, still over 400k a month. WPML bundles it on 1.5 million WordPress sites. It also rode idna-convert into SPIP, Debian, and Ubuntu. A trailing-slash workaround strips every letter "a" from paths. He's deprecating the package rather than handing it to a new maintainer, after the xz Utils story. Use the PHP League URI library or PHP 8.5's URI API. AOL never migrated off it. The CMS died around 2020 still running the shim. 230 points.
