Spymarks, Not Watermarks

Brandon Thomas wants a new word for invisible tracking watermarks: spymarks. Google SynthID-O can hide a 136-bit payload in a 512x512 image, enough for a 64-bit database ID plus error correction. Unlike EXIF, you can't inspect or strip it; the signal lives in pixels, audio, or word choice.

Can gzip be a language model?

Nathan ran gzip (zlib DEFLATE) as a language model: prime a 32 KiB window on a corpus, then beam-search the next bytes that compress smallest. On tiny Shakespeare you get half-coherent junk that still sounds like the play. One Python file, no weights.
